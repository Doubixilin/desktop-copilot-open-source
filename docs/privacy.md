# 数据与安全边界

公开仓库没有用户的真实记录。安装后启用真实模式，程序处理的内容可能敏感；“本地工作台”描述部署位置，不能理解为所有数据始终不出本机。

## 三种使用方式

| 方式 | 数据来源与动作 |
| --- | --- |
| 独立演示 `demo/serve.py` | 只提供白名单静态资源和合成样例；没有真实文件搜索、采样、窗口探测、日程写回或模型请求 |
| 本地真实服务与 HUD | 读取支持工具的本地会话、文件元数据、进程使用情况与窗口材料；写本地任务库、反馈、快照、日志与归档；可改变图标坐标 |
| 配置执行端和外部账户 | 任务文本、路径引用及附带的现场正文可进入执行端；执行端配置的模型服务可能远程接收材料；滴答请求、额度接口使用对应账户凭据 |

## 真实模式读取什么

会话采集器读取支持客户端的记录文件或只读 SQLite，可能解析项目目录、会话标题、消息预览、任务与 token 信息。Kimi Work 的适配在数据不可得时只提供降级字段。客户端格式改变可能影响结果；不要将其当作官方跨工具审计接口。

文件搜索依赖本机索引服务，获得名称、路径、类型、大小和修改时间。打开/定位是真实文件动作；交给副驾的路径引用可能被执行端进一步读取，取决于其权限与工具实现。

现场采集可能包含进程路径、窗口标题、IDE 选区、终端尾部、弹窗文本及 OCR 文字。截图 OCR 的当前实现将图像放在内存并输出文字，不主动保存截图；冻结的文字现场包和执行归档会落到本地数据目录。文字同样可能暴露个人或业务信息。

剪贴板事件只记录格式元数据；召唤时按需读取文件列表，不读取文本正文。这一限制仅针对本项目剪贴板适配，不能约束外部执行端或其他应用。

应用使用日志设计为时间戳与进程路径，不采集窗口标题；会话采集、现场材料和副驾归档是独立数据路径，不能据此宣称整套应用不处理标题或正文。

## 存储位置

| 位置 | 内容 |
| --- | --- |
| `%LOCALAPPDATA%/qoder-deck/copilot/` | 本地配置、任务 SQLite、现场包、反馈、归档及副驾运行资料；可由 `QD_COPILOT_DIR` 覆盖 |
| `%LOCALAPPDATA%/qoder-deck/api-token` | 本机控制接口令牌 |
| `%LOCALAPPDATA%/qoder-deck/dida.json`、`quota.json` | 外部账户和额度配置，可能包含凭据 |
| `%LOCALAPPDATA%/qoder-deck/layout/`、`usage/` | 图标布局快照、进程使用日志 |
| `%LOCALAPPDATA%/AgentDeckNativeHud/` | 原生宿主诊断与 WebView2 用户数据 |
| 用户配置的 `runtime.dsh_home` | 执行端配置、会话和工具记录 |

这些目录默认由 Windows 用户文件权限保护，项目没有实现所有本地内容的统一加密。操作系统账户访问、备份、同步盘和执行端权限也会影响隐私。停用副驾不会自动删除历史材料。

## 网络与执行权限

数据服务默认绑定 `127.0.0.1`。Host/CORS 校验与本机令牌限制控制接口；公开的看板数据端点并非都带令牌，可能包含会话预览。本机其他进程也可能访问回环端口，不应把回环监听当作账户隔离或生产级鉴权。不要反向代理到公网。

原生页面只加载本地资源，宿主通过窄协议转发请求。执行端的权限与沙箱仍是实际工具访问边界：工作区内写操作可能直通，许可问答只在执行端提出请求时出现。不得把“有许可按钮”解释成“所有改动都需逐次批准”。

滴答完成待办会发送真实写回；额度接口可能访问服务商网络；DSH 是否出网、提交什么材料、保留多久，由用户配置的运行时和模型服务共同决定。默认副驾关闭、没有附带外部凭据。

## 公开分享前

只使用 `demo/serve.py` 的合成界面截图分享 UI。真实桌面截图可能露出图标名称、文档、路径、通知、会话预览和账户内容。问题报告应提供最小合成复现，不上传真实数据库、运行时 home、token 文件、日志全集或归档。

仓库 `.gitignore` 只是防误提交辅助，不能清除已进入 Git 历史的内容。后续公开更新应沿用白名单导出和提交内容审查，不从私有仓库直接合并历史。本次处理的是公开版本的发布范围，并不是对程序所有数据路径做过完整安全审计。
