# 公开版本范围

本公开仓库以 2026 年 10 月 11 日的当前 Python 与原生 HUD 源码整理为独立快照。采用新的 Git 历史，原私有开发仓库继续保持私有；公开仓库不引用或同步其分支、标签和历史对象。

## 保留的内容

Python 数据服务、会话与用量适配、桌面坐标编排、搜索适配、ACP 副驾控制器、任务存储、现场包、归档、结算、Windows 原生宿主、实际 HUD 页面、两套自建会话看板、合成测试与无凭据示例。另提供独立无模型浏览器演示、截图、入门、架构、隐私、验证和贡献文档。

## 排除的内容

| 类别 | 处理 |
| --- | --- |
| Git 开发历史、私有分支与提交身份 | 从干净仓库开始，不公开原历史 |
| `.scratch/` 工单、实验、验收与探针材料 | 整体排除，不按“看起来是测试”默认公开 |
| 实机截图、录屏、桌面文件名与窗口内容 | 整体排除，使用合成数据重渲染实际 UI |
| 会话导出、数据库、日志、运行时 home 与配置 | 不复制到公开快照 |
| API Key、令牌、账户口令、私有端点 | 不发布；示例只保留占位与禁用配置 |
| 原始第三方壁纸、备份、补丁副本 | 不发布 |
| 商业字体、创意工坊字体和背景素材 | 不发布，不提供自动复制或下载机制 |
| 本机用户名、仓库路径与内部业务材料 | 排除非公开材料，诊断与示例改为通用示例路径 |
| 构建产物、缓存、安装包和 OCR 模型 | 不发布，由使用者按需自行准备 |
| 长期记忆等尚未完成的规划 | 只列后续方向，不夹带内部规划或声称已实现 |

现有代码注释中的阶段/票号是开发背景标识，所指内部 `.scratch` 文档不在公开版；公开文档提供可阅读的功能与架构说明，不依赖内部票据。

## 与私有版本的有意差异

公开页面使用系统字体，旧 Tk 面板不再扫描 Steam 创意工坊寻找商业字体；不带实机截图采集和字体复制部署脚本。示例执行端目录改为 `C:/example/` 占位。功能实现保留，但所有个人配置与数据需使用者重新准备。

本次从原工作区按白名单复制了 128 个源码/测试/示例文件，排除了 1,092 个已跟踪的非公开文件，再添加公开文档和合成演示。排除数量说明快照整理范围，不是隐私零残留的统计证明。

## 后续更新

1. 从私有工作区导出需要公开的源码与合成测试，不复制 `.git`。
2. 检查实际内容与文件名，包括路径、凭据、样例正文、图片和许可证。
3. 更新公开功能说明、合成截图和配置边界。
4. 在公开工作区运行适当的测试、原生构建和泄露检查。
5. 只暂存明确审核过的公开文件；不把测试生成的数据加入提交。

忽略规则不等于发布许可。加入新的第三方组件或素材时，先确认其来源、许可与分发要求。
