## 全套 Python 回归的限制

排除真实截图/OCR 测试文件后的一轮测试为 **668 项通过、1 项失败**，失败发生在本机 Tk 初始化，提示 Tcl/Tk 资源无法加载。失败用例单独重跑通过；随后组合运行又出现同类 Tk 资源初始化失败，因此不能把它归为已经彻底解决的偶发问题。还观察到 ACP 取消测试的事件循环/管道回收警告。

旧 Tk 搜索面板属于独立于原生 HUD 的界面路径。CI 选用已验证的 112 项核心回归，不包含 Tk 实机窗口与截图/OCR。没有删除失败用例或改成无条件跳过，也没有为发布修改本机 Python/Tk 安装。

594 项回归的复现命令（显式排除 Tk 窗口测试与真实截图/OCR）：

```powershell
python -m pytest tests -q --ignore=tests/test_native_hud_capture.py --ignore=tests/test_search_panel.py --ignore=tests/test_search_timing.py --ignore=tests/test_copilot_review_fixes.py --ignore=tests/test_copilot_panel.py --ignore=tests/test_copilot_g1_flow.py
```

## 发布整理中修正的内容

- 公开版使用系统字体，不再私有加载商业字体；无字体路径时不调用字体加载接口。
- HUD 演示标识补齐页面 ID，避免实际浏览器渲染时因取不到节点中断。
- 现场探测结果到达后立即刷新材料条与布局。
- 本机 HTTP 交接测试改用合成快照、测试令牌和临时端口，避免读取真实会话及硬件。
- 示例与测试目录改为通用占位，真实配置保持仓库外存放。

这些调整仅在公开快照中实施，不能据此认定私有开发分支同步应用了同样改动。

## 发布材料检查

使用白名单导出，不复制 Git 历史、`.scratch`、运行数据、原始截图、字体或第三方壁纸。`scripts/check_public.py` 对暂存/跟踪文件检查禁止路径、常见密钥模式、个人路径和 Markdown 本地链接；它不保证检测任意隐私信息。图片目检和实际内容检查独立完成。

## 尚需实机或外部验证

原生背景材质、不同 Windows 版本、多屏 DPI、焦点、中文输入法、Win+D、快捷键冲突、长时间运行和 Explorer 更新后的编排兼容性需要在目标设备验证。真实 Everything/Listary、DSH 模型与许可、滴答写回、本地 OCR 覆盖，以及真实材料的出站边界没有作为本次公开发布联调。

浏览器演示、合成测试、构建成功和真实业务验收分别代表不同范围，不相互替代。
